# Promorg 1.3.1

Draft notes for the GitHub release `v1.3.1`. Paste everything below the line into the release description.

---

**Promorg 1.3.1: Open in Gmail opens the email again, release dates written a little differently are read, and the window opens a bit smaller.**

**Install:** download `Promorg-1.3.1-Setup.exe` and run it, or use `Promorg-1.3.1-Standalone.exe`, which needs no
install. If the .NET 10 Desktop Runtime isn't on the PC, the installer offers to download and install it from
Microsoft. Neither file is code-signed, so Windows SmartScreen may warn you: click **More info**, then **Run anyway**.

**Updating**
- **From Promorg 1.3.0:** **Settings › About & updates › Check for updates**, then **Download and install**. The
  update is checked against its release signature before it runs. Your mail, releases, settings and look are kept.
- **From an older Promorg (1.0.0 or 0.5.4) or Promo Organiser 0.2.0:** update the same way. Everything in 1.3.0 is in
  1.3.1, so read the **1.3.0 release notes** too: they cover the one-way database upgrade, typing a password again for
  a mailbox on an unlisted mail server, and, from Promo Organiser, closing it first and re-pinning Promorg on the
  taskbar.

**Fixed**
- **Open in Gmail** (in Messages, Direct and Other, and the email reader) opens the email in its mailbox's Google
  account again. In 1.3.0 it showed Gmail's "Temporary Error (404)" page instead. **Open in Gmail** in Create, and
  for a reply in Tracks, had the same fault and is fixed too.
- **Release dates:** a FATdrop promo whose date line has a ';' or a dash where the ':' usually is
  ("Releasedate; 12 Dec 2026") now gets its release date. The first start after updating re-reads your stored mail
  once, in the background, so promos already in Promorg get theirs too.
- **The window** opens a little smaller: most of your screen, but no longer almost all of it (never smaller than
  before 1.3.0).

**Known issues**
- Starting Promorg a second time sometimes says "Promorg is already running…" even though the first copy is fine.
  This can happen when it's started from a launcher or script, or while the first copy is still starting. Switch to
  the Promorg window that's already open.
- If a backup or security program briefly holds Promorg's lock file, Promorg may also say it's already running when
  it isn't. Try again in a moment.
- Promo-Cloud tracklists that name versions in unusual ways can give a wrong artist, or none. Examples are
  "Sunrise Run - Kay Vee Edit", or a track that's just called "Original". An artist worked out from a tracklist is
  always marked ⚠ to check: correct it, or click **They're right**.
- A fresh install on a PC without .NET, and running Setup without a network connection, haven't been tested on a
  clean PC for this release.

**Files**
- `Promorg-1.3.1-Setup.exe`: the installer.
- `Promorg-1.3.1-Standalone.exe`: the standalone app (no install, .NET included).
- `.sha256`: each file's SHA-256, for checking by hand.
- `.sig`: each file's release signature, which the app checks before installing an update.
- `PromoOrganiser-1.3.1-Setup.exe` and its `.sig`: the same installer under the old name, only so that Promo
  Organiser 0.2.0 finds the update by itself. Download the `Promorg-` files.
