# Promorg 1.0.0

Draft notes for the GitHub release `v1.0.0`. Paste everything below the line into the release description.

---

**Promorg 1.0: a new look.** The same app, easier on the eye: each part of a view has its own card, your Windows
accent colour marks where you are, and the details pane leads with the release itself.

**Install:** download `Promorg-1.0.0-Setup.exe` and run it, or use `Promorg-1.0.0-Standalone.exe`, which needs no
install. If the .NET 10 Desktop Runtime isn't on the PC, the installer offers to download and install it from
Microsoft. Neither file is code-signed, so Windows SmartScreen may warn you: click **More info**, then **Run anyway**.

**Updating**
- **From Promorg 0.5.4:** **Settings › About & updates › Check for updates**, then **Download and install**. The update
  is checked against its release signature before it runs. Your mail, releases and settings are kept.
- **From Promo Organiser 0.2.0:** the same, in Promo Organiser. Your mail, releases, settings and saved passwords move
  over to Promorg on its first start.
  - **Close Promo Organiser before running the Standalone** (or the installer, if you run it by hand). If it's still
    open, Promorg asks you to close it first. If you can't see its window, end PromoOrganiser.exe in Task Manager
    (Ctrl+Shift+Esc).
  - **Re-pin Promorg on the taskbar.** A pin made for Promo Organiser points at the old program, which the update
    removes.
  - **Don't go back to Promo Organiser 0.2.0** after Promorg's first start: your data has moved, so it would open empty.

**New in 1.0**
- **Cards:** the tabs and filters, the list, and the details or reading pane each sit on their own card, instead of one
  box around everything.
- **A heading row:** the view's name at the top, with **Refresh** and **Add promo** beside it.
- **Your accent colour:** the selected status tab is filled with your Windows accent colour, and the selected view on
  the left and its counts use it too (in a Windows contrast theme, its Highlight colours). Each status tab has its own
  colour dot and a count.
- **The details pane** opens with the release's artist, title, label and catalogue number, then its actions, then the
  fields, in sections. The distributor and a link you typed in are under **More details**.
- **The reading pane** (Messages, Direct, Other) shows each email's header as a band at the top of one card.
- **Received** sits beside the release date in Promos, and right after the sender in the email lists. In a narrower
  window the Promos list keeps the received date, except on the All mailboxes tab with several mailboxes, where it
  keeps the Mailbox column instead so each promo's mailbox still shows.

**Known issues**
- Starting Promorg a second time sometimes says "Promorg is already running…" even though the first copy is fine.
  This can happen when it's started from a launcher or script, or while the first copy is still starting. Switch to
  the Promorg window that's already open.
- If a backup or security program briefly holds Promorg's lock file, Promorg may also say it's already running when
  it isn't. Try again in a moment.
- The first start after an update from 0.2.0 re-reads your stored mail in the background. Releases with many
  Promo-Cloud or Promoly emails make it slower.
- Promo-Cloud tracklists that name versions in unusual ways can give a wrong artist, or none. Examples are
  "Sunrise Run - Kay Vee Edit", or a track that's just called "Original". An artist worked out from a tracklist is
  always marked ⚠ to check: correct it, or click **They're right**.

**Files**
- `Promorg-1.0.0-Setup.exe`: the installer.
- `Promorg-1.0.0-Standalone.exe`: the standalone app (no install, .NET included).
- `.sha256`: each file's SHA-256, for checking by hand.
- `.sig`: each file's release signature, which the app checks before installing an update.
- `PromoOrganiser-1.0.0-Setup.exe` and its `.sig`: the same installer under the old name, only so that Promo
  Organiser 0.2.0 finds the update by itself. Download the `Promorg-` files.
