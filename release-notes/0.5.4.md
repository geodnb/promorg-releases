# Promorg 0.5.4

Draft notes for the GitHub release `v0.5.4`. Paste everything below the line into the release description.

---

**Promo Organiser is now Promorg.** This is the first release under the new name, and the first since 0.2.0.

**Install:** download `Promorg-0.5.4-Setup.exe` and run it, or use `Promorg-0.5.4-Standalone.exe`, which needs no
install. If the .NET 10 Desktop Runtime isn't on the PC, the installer offers to download and install it from
Microsoft. Neither file is code-signed, so Windows SmartScreen may warn you: click **More info**, then **Run anyway**.

**Updating from Promo Organiser 0.2.0**
- In Promo Organiser, use **Settings › About & updates › Check for updates**, then **Download and install**. The
  update is checked against its release signature before it runs. Your mail, releases, settings and saved passwords
  move over to Promorg on its first start.
- **Close Promo Organiser before running the Standalone** (or the installer, if you run it by hand). If Promo
  Organiser is still open, Promorg asks you to close it first. If you can't see its window, end PromoOrganiser.exe
  in Task Manager (Ctrl+Shift+Esc).
- **Re-pin Promorg on the taskbar.** A taskbar or Start pin made for Promo Organiser points at the old program, which
  the update removes. Pin Promorg again from the Start menu.
- **Don't go back to Promo Organiser 0.2.0** after Promorg's first start. Your data and saved passwords have moved to
  Promorg, so Promo Organiser would open empty.
- The first start re-reads your stored mail with the new promo readers. A progress line shows at the bottom.

**New since 0.2.0**
- **More mail services:** Yahoo, iCloud, AOL, Fastmail, Zoho or any other IMAP mailbox, as well as Gmail (not Outlook
  or Hotmail yet). Each mailbox gets its own tab, with its own releases, statuses and notes.
- **More promo services:** Inflyte, Promo-Box, Promoly and Promo-Cloud, plus labels that mail their own promos, as well
  as FATdrop and Label Engine. Promos from senders the app doesn't know yet arrive marked ★ to confirm. Invitations
  to receive a label's promos are marked ✉, and platforms' weekly summaries ≡.
- **White labels:** "Unknown Artist" is shown as the label gives it, and replaced when a later email names the
  artist. **Search the web** looks a release up when its email doesn't say who it's by.
- **Setlist:** your own ordered lists of promos, for a set, a show or a mix.
- **Download a promo:** its cover art, a text file of its details, or both.
- **Remove releases** you don't want; their emails stay.
- Mail is fetched automatically every 15 minutes while the app is open.
- Help built in (**?** or F1), more keyboard shortcuts, and backups and CSV export in Settings › Maintenance.
- **Check a download:** an installed copy can check any download's signature.

**Files**
- `Promorg-0.5.4-Setup.exe`: the installer.
- `Promorg-0.5.4-Standalone.exe`: the standalone app (no install, .NET included).
- `.sha256`: each file's SHA-256, for checking by hand.
- `.sig`: each file's release signature, which the app checks before installing an update.
- `PromoOrganiser-0.5.4-Setup.exe` and its `.sig`: the same installer under the old name, only so that Promo
  Organiser 0.2.0 finds the update by itself. Download the `Promorg-` files.
